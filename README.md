# StarBlaze Personal Website

StarBlaze 是一个使用原生 HTML、CSS 和 JavaScript 编写的个人主页，包含简介、摄影、天文和编程页面。

## 技术栈

- HTML5
- CSS3
- JavaScript
- Git

## 本地运行

这是一个静态网站，不需要构建工具。可以使用任意静态文件服务器运行，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 目录说明

- `index.html`：个人简介
- `photograph.html`：摄影作品
- `astro.html`：天文作品
- `programming.html`：编程方向与学习情况
- `share/`：共享样式和交互脚本
- `photograph/`、`astro/`、`programming/`：各页面资源

## 当前方向

关注后端工程、LLM 训练和 Agent 基础建设。算法训练、数据库设计、自动化测试、Linux 运维及大型项目协作仍在持续学习中。
